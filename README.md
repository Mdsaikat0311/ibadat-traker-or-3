# ইবাদত ট্র্যাকার (Ibadat Tracker) - React Web Application

একটি পূর্ণাঙ্গ ইসলামিক আমল, দৈনিক সালাত, তাহাজ্জুদ, নফল, যিকির ও কুরআন ট্র্যাকার ওয়েব অ্যাপ্লিকেশন।

## প্রধান সুবিধাসমূহ

- **সালাত ও তাহাজ্জুদ ট্র্যাকার**: দৈনিক ৫ ওয়াক্ত ফরয সালাত, প্রতিটি সালাতের পর দু'আ ও যিকির (+5p), সকালের যিকির (+3p), সন্ধ্যার যিকির (+3p), এবং তাহাজ্জুদ সালাত (+20p)।
- **নফল ইবাদত**: ইশরাক (চাশত), আউয়াবিন, সালাতুল ইস্তিখারা, তাহিয়্যাতুল মসজিদ, সুন্নাতুল ওযু (+10p প্রতিটি)।
- **দৈনিক আমল ও রুটিন**:
  - বিশেষ আমল (দান ও সদাকা)
  - সকাল-সন্ধ্যার রুটিন (সারাদিন যিকির, ঘুম থেকে ওঠার দু'আ, সকালে কুরআন পড়া, ৩ কুল ও হাশরের শেষ ৩ আয়াত, দরূদ শরীফ, ইত্যাদি)
  - রাতের রুটিন (ঘুমানোর আগে ২ রাকাত, ঘুমের দু'আ, সূরা বাকারার শেষ ২ আয়াত, সূরা মুলক, পিতা-মাতার জন্য দু'আ)
  - কুরআন রুটিন (সূরা মুলক, আর-রহমান, ইয়াছিন, কাহফ, বাকারা, শেষ ১০ সূরা)
- **যিকির চেকলিস্ট**: সুবহানাল্লাহ, আলহামদুলিল্লাহ, আল্লাহু আকবার, সাইয়্যিদুল ইস্তিগফার, আস্তাগফিরুল্লাহ, লা হাউলা ইত্যাদি আরবি পাঠ ও অর্থসহ।
- **ইসলামিক নোটবুক ও লাইব্রেরি**: ব্যক্তিগত দু'আ ও আমল নোট সংরক্ষণ এবং হাদীসের গুরুত্বপূর্ণ লাইব্রেরি নোট।
- **সারাংশ ও হিটম্যাপ ক্যালেন্ডার**:
  - যেকোনো তারিখের ডেটা দেখা ও আপডেট করার তারিখ নির্বাচন বার
  - মাসিক কালার-কোডেড হিটম্যাপ ক্যালেন্ডার
  - গত ৭ দিনের ফরয সালাতের পার্সেন্টেজ ও ভিজ্যুয়াল বার চার্ট
  - ৫ ক্যাটাগরির সেরা পারফর্মার লিডারবোর্ড (আজকের সেরা, গতকালকের সেরা, সাপ্তাহিক ৭ দিন, মাসিক ৩০ দিন, সর্বমোট লাইফটাইম)
- **প্রোফাইল ও সেটিংস**:
  - প্রোফাইল নাম ও লাইফটাইম শুরুর তারিখ পরিবর্তন
  - স্বয়ংক্রিয় হাদিস রিমাইন্ডার টগল
  - তাওবা ও যিকির রিমাইন্ডার এবং সময় ব্যবধান নির্ধারণ
  - কুরআনের বাণী ও হাদিসের অনুপ্রেরণামূলক র্যান্ডম উদ্ধৃতি
  - সমস্ত ডেটা রিসেট সুবিধা

## প্রযুক্তি

- React 19 + TypeScript
- Vite 6
- Tailwind CSS v4
- Lucide React Icons
- LocalStorage Persistence
